### 2.1 Contract Details

| Attribute | Value |
|-----------|-------|
| HTTP method | `POST` |
| Path | `/api/v1/ai/chat` |
| Authentication | `bearerAuth` (JWT) |
| Authorization | Server-side role resolution via `FamilyMemberRepository`; cross-family resolves to `RESTRICTED` |
| Request body | `AIChatRequest` (JSON) |
| Response body | `AIResponse` (JSON) |
| Error responses | `400`, `401`, `403`, `500` using the existing `Error` schema |
| Correlation ID | Not implemented in MVP |
| Rate limiting | Not implemented in MVP |
| Audit | Every request is recorded via `AuditService` (`AI_REQUEST_PROCESSED`) |

## 3. OpenAPI Changes

Added to `NeoWallet_OpenAPI_v1.yaml`:

### 3.1 Schemas

- `AIChatRequest`
- `AIResponse`
- `AIToolExecutionRecord`

### 3.2 Path

- `POST /api/v1/ai/chat`

The endpoint is tagged under `AI` and secured with `bearerAuth`. It references the new schemas and the existing `Error` schema for all error responses.

### 3.3 Request Schema (`AIChatRequest`)

```yaml
AIChatRequest:
  type: object
  required:
    - message
  properties:
    familyId:
      type: string
      format: uuid
      nullable: true
    message:
      type: string
    sessionId:
      type: string
      nullable: true
```

### 3.4 Response Schema (`AIResponse`)

```yaml
AIResponse:
  type: object
  required:
    - responseId
    - type
    - text
    - refusal
  properties:
    responseId:
      type: string
      format: uuid
    userId:
      type: string
      format: uuid
    familyId:
      type: string
      format: uuid
      nullable: true
    type:
      type: string
      enum:
        - FACT
        - ANALYSIS
        - RECOMMENDATION
        - WARNING
        - INSUFFICIENT_DATA
        - REFUSAL
    text:
      type: string
    toolExecutions:
      type: array
      items:
        $ref: '#/components/schemas/AIToolExecutionRecord'
    citedFacts:
      type: array
      items:
        type: string
    metadata:
      type: object
      additionalProperties: true
    refusal:
      type: boolean
```

### 3.5 `AIToolExecutionRecord` Schema

AIToolExecutionRecord:

      type: string
    allowed:
      type: boolean
