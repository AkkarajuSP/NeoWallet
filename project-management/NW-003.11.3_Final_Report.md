# NW-003.11.3 — Neo AI Specialist Agents Final Report

## Scope

Implement the Neo AI specialist-agent capability layer as an extension of the existing `AIOrchestrator` and `NeoConcierge` foundation. No new AI execution, payment, UPI, bank transfer, or family-authorization changes were introduced. NW-003.12 was not started.

## Architectural approach

Specialist agents are **logical capabilities inside the existing orchestration layer**, not independent LLM services.

Components reused:
- `NeoConcierge` (front-end conversational entry)
- `IntentClassifier`
- `AIOrchestrator`
- `PolicyEngine`
- `ToolRegistry`
- `AIProvider`
- `Conversation`
- `Audit`

New components:
- `com.neowallet.ai.agent.Agent` interface
- `com.neowallet.ai.agent.ConciergeAgent`
- `com.neowallet.ai.agent.FinancialAnalysisAgent`
- `com.neowallet.ai.agent.BudgetAgent`
- `com.neowallet.ai.agent.SavingsAgent`
- `com.neowallet.ai.agent.BillAgent`
- `com.neowallet.ai.agent.FinancialHealthAgent`

## Agent routing

`AIOrchestrator` now selects the highest-priority agent that supports the classified `IntentType`:

| Intent | Specialist agent |
|---|---|
| `FINANCIAL_OVERVIEW`, `TRANSACTION_ANALYSIS` | `FinancialAnalysisAgent` |
| `BUDGET_ANALYSIS`, `BUDGET_HELP` | `BudgetAgent` |
| `SAVINGS_ANALYSIS`, `SAVINGS_HELP` | `SavingsAgent` |
| `BILL_ANALYSIS`, `BILL_HELP` | `BillAgent` |
| `FINANCIAL_HEALTH_QUERY`, `FINANCIAL_HEALTH_EXPLANATION` | `FinancialHealthAgent` |
| `GREETING`, `GENERAL_FINANCIAL_QUESTION`, `RECOMMENDATION_REQUEST`, `UNKNOWN`, `INSUFFICIENT_DATA`, `UNSUPPORTED_REQUEST` | `ConciergeAgent` |

## Capabilities implemented

### 1. Financial Analysis Agent
- spending analysis
- category analysis
- spending trends
- transaction summaries
- period comparison
- top spending categories
- unusual spending identification

### 2. Budget Agent
- budget explanation
- utilization explanation
- category variance explanation
- budget forecast explanation
- budget recommendation explanation
- spending-vs-budget analysis

### 3. Savings Agent
- savings goal progress explanation
- contribution analysis
- forecast explanation
- monthly contribution recommendations
- goal prioritization suggestions

### 4. Bill Agent
- upcoming bill summary
- overdue bill explanation
- recurring bill analysis
- bill planning recommendations

### 5. Financial Health Agent
- current Financial Health score explanation
- factor score explanation
- positive/negative factor explanation
- score-change explanation
- improvement area recommendations

All agents are **read-only and recommendation-only**. They cannot modify, pay, move, or override anything.

## Safety features retained

- `PolicyEngine` still blocks financial-execution keywords, prompt-injection patterns, and denied tools.
- `AIOrchestrator` still enforces `INSUFFICIENT_DATA` when authoritative tool results are null, empty, missing, invalid, or unavailable.
- Every agent prompt instructs the model to use only the provided authoritative data.
- `FinancialHealthAgent` explicitly cannot calculate, modify, or override the deterministic score, weights, or thresholds.
- Audit metadata now includes the resolved `agent` name for every orchestrated response.

## Tool access

All agents use the existing `ToolRegistry` read-only tool set:

- `FinancialAnalysisAgent` → `getFinancialOverview`, `getTransactions`
- `BudgetAgent` → `getFinancialOverview`, `getBudget`
- `SavingsAgent` → `getSavingsGoals`, `getFinancialOverview`
- `BillAgent` → `getBills`
- `FinancialHealthAgent` → `getFinancialHealth`

No new write tools, payment tools, or database access were introduced.

## Output types

Agents use the existing `AIResponseType` enum:
- `FACT`
- `ANALYSIS`
- `RECOMMENDATION`
- `WARNING`
- `INSUFFICIENT_DATA`
- `REFUSAL`
