# NW-003.12.2.1 NeoWallet Brand & Logo Integration Report

## 1. Objective

Integrate the two approved NeoWallet logo assets into the Flutter application according to the provided brand usage rules:

- **Splash screen only**: `NeoWallet-HR-Vertical.png`
- **All other application screens requiring branding**: `NeoWallet-HR-Horizontal.png`

No logo asset was modified, redesigned, recolored, cropped, or replaced.

## 2. Approved Asset Inventory

| File | Path | Usage |
|---|---|---|
| NeoWallet-HR-Vertical.png | `neowallet/mobile/neowallet-app/assets/branding/NeoWallet-HR-Vertical.png` | Splash screen only |
| NeoWallet-HR-Horizontal.png | `neowallet/mobile/neowallet-app/assets/branding/NeoWallet-HR-Horizontal.png` | All other branding locations |

The previous directory was renamed from `asserts/branding` to `assets/branding` to align with Flutter conventions.

## 3. pubspec.yaml Asset Declaration

The branding directory was added to `pubspec.yaml`:

```yaml
flutter:
  uses-material-design: true

  assets:
    - .env
    - assets/branding/
```

## 4. Reusable Components Created

`lib/core/components/brand_logos.dart` centralizes all logo usage:

- `NeoWalletSplashLogo` — displays `NeoWallet-HR-Vertical.png` with `BoxFit.contain` and a `semanticLabel`.
- `NeoWalletHorizontalLogo` — displays `NeoWallet-HR-Horizontal.png` with `BoxFit.contain` and a `semanticLabel`.
- `BrandAppBar` — a `PreferredSizeWidget` that places the horizontal logo in the leading position and supports `title`, `actions`, `bottom`, and `centerTitle` parameters.

All components preserve the original aspect ratio and do not recolor, crop, stretch, or distort the assets.

## 6. App Icon Assessment

The existing Android launcher icons in `android/app/src/main/res/mipmap-*/ic_launcher.png` are the default placeholders and are not the approved NeoWallet logos. The approved assets are full wordmark logos with text, which are not suitable as small launcher icons. A dedicated, simplified app launcher icon is required.

**Recommendation**: Produce a dedicated `ic_launcher` asset set (e.g., an `ic_launcher.png` at each density and a `ic_launcher_foreground.png`/`ic_launcher_background.png` for adaptive icons) and update `mipmap-hdpi`, `mipmap-mdpi`, `mipmap-xhdpi`, `mipmap-xxhdpi`, and `mipmap-xxxhdpi`. Do not use `NeoWallet-HR-Vertical.png` or `NeoWallet-HR-Horizontal.png` directly as launcher icons.
