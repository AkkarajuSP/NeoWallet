# NW-003.12.2 — NeoWallet Mobile Design System & Home Dashboard

**Date:** 2026-08-20
**Status:** Completed

## 1. Objective

Implement a centralized NeoWallet mobile design system and a production-quality Home Dashboard that:

- Exposes design tokens for colors, typography, spacing, border radius, cards, buttons, inputs, app bars, bottom navigation, status indicators, and financial amount formatting.
- Builds reusable dashboard components driven by real backend data.
- Clearly distinguishes planning, actual, pending, and available financial capacity with labels and disclaimers.
- Handles loading, success, empty, error, unauthorized, and session-expired states for every Home section.
- Provides a prominent but non-intrusive Neo AI entry point with example prompts.
- Remains responsive on small/large screens, supports scrolling, keyboard, and accessibility text scaling without horizontal overflow.
- Adds Flutter tests covering the design system and dashboard components.
- Verifies with `flutter analyze`, `flutter test`, `flutter build apk --debug`, `mvn clean verify`, and OpenAPI validation.

## 4. Implementation Highlights

- **Financial safety UX:** `FinancialSummaryCard` groups values into `PLANNING`, `ACTUAL & PENDING`, and `AVAILABLE CAPACITY` sections and surfaces the planning-versus-bank-balance disclaimer from `DesignTokens.planningDisclaimer`.
- **Real backend data:** `HomeScreen` watches `financialOverviewProvider`, `budgetListProvider`, `savingsGoalListProvider`, `billListProvider`, `financialHealthProvider`, and `transactionListProvider` scoped to the selected family.
- **State handling:** Each dashboard section independently renders `LoadingState`, `ErrorState` with retry, `EmptyState`, or the data card.
- **Family context:** `FamilySelector` loads families from `familiesProvider`; `HomeScreen` bootstraps the selected family from the user profile and falls back to the first available family.
- **Neo AI entry:** `NeoInsightCard` is surfaced at the bottom of the Home feed with three example prompts and navigates to `/neo`.
- **Responsive layout:** `HomeScreen` uses `SingleChildScrollView`, `LayoutBuilder`, and `ConstrainedBox` to adapt to small and large screens.
